=== PART 1: WEB TECHNOLOGIES ===

1. What is a website?
    - A website is a collection of related web pages that are stored under one domain and can be accessed using a web browser. These pages may contain text, lists, links, images, and other information about a particular topic.
2. What happens when a user enters a website address into a web browser?
    - When a user enters a website address, the browser sends a request through the internet to the web server where the website is stored. The server then finds the requested page and sends it back to the browser, which reads the HTML and displays the content on the screen.
3. What is the role of a web browser in accessing a website?
    - A web browser allows users to access and view websites. It requests the web pages from a server or local folder, reads the files it receives, and displays their content so users can browse the pages and click links.
4. What is the difference between HTML and CSS?
    - HTML is used to create the structure and organize the content of a web page, such as headings and paragraphs. Meanwhile, CSS is used to control how those elements look, including their colors, fonts, spacing, and layout.
5. Why is HTML important in creating a website?
    - HTML is important because it provides the basic structure of a website. It organizes the content, such as text, links, lists, and images, so the browser can properly display and understand it. Without HTML, there would be no proper structure for CSS and other web technologies to work with.

=== PART 5: DEBUG LOG ===

Problem: In index.html, our custom visual images were displayed at their full original size, making them extremely large on the screen. This also caused steps 3 and 5 to overlap and become hidden.
Tool Used: Browser viewport inspection and source code review.
Fix: Added the HTML width="700" attribute directly to both img tags so the images would scale proportionally and fit the screen properly without using CSS, as required.

Entry 2
Problem: In about.html, the team table used old HTML4 presentation attributes (border, cellpadding, and cellspacing). It also had missing scope attributes on the table header cells, which were flagged as errors by the W3C Markup Validator.
Tool Used: W3C Markup Validation Service inspection and Browser Developer Tools.
Fix: Removed the deprecated presentation attributes and added scope="col" and scope="row" attributes to the table headers to make sure the table follows HTML5 validation standards.
